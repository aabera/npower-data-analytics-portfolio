Summary Table: Feature Selection Approaches
Depending on these criteria, data scientists use three main algorithmic approaches to filter features:
Approach	How it Works	Example
Filter Methods	Evaluates features independently of the model based on statistical properties.	Correlation matrix, Chi-Square test, Variance Threshold.
Wrapper Methods	Uses a model to evaluate combinations of features, adding or removing them iteratively.	Forward Selection, Backward Elimination, Recursive Feature Elimination (RFE).
Embedded Methods	Feature selection happens natively during the model training process.	Lasso (L1) Regression penalty, Decision Tree Feature Importances.
